# Данные диаграмм

Схемы кейсов рисуются компонентом `src/components/Diagram.astro` только из этих файлов. Нотация — `ds/patterns.md` §Диаграммы, токены — `ds/foundation.md` §Диаграммы.

```
src/data/diagrams/
  schema.ts            типы и defineDiagram()
  kit/                 образцы для /kit: map, flow, prototype, library
  <кейс>/<вид>.ts      данные кейса, например agent-ops/map.ts
```

**Почему TS, а не JSON:** опечатку в id узла и неизвестный тип элемента ловит `astro check`, а подписи EN/RU лежат рядом с геометрией в одном файле.

## Подключение

```astro
---
import Diagram from '../components/Diagram.astro';
import map from '../data/diagrams/agent-ops/map.ts';
---
<Diagram data={map} lang="ru" />

<!-- тёмная тема кейса — атрибут на предке -->
<section data-theme="dark"><Diagram data={map} /></section>
```

## Общие правила

- **Координаты и размеры — в клетках** `--diagram-cell` (8 px). `at: [x, y]` — левый верхний угол. Пикселей в данных нет.
- **Подписи — `{ en, ru }`.** Геометрия у локалей одна. Ширина узла без `w` считается по самой длинной локали.
- **Поле `size: { w, h }`.** Компонент добавляет вокруг него отступ `--diagram-pad` (24 px), что за отступом — обрезается. Для колонки кейса держите `w` до 155.
- **Прототип:** хотспот ставьте на блок, который нажимают (строка, кнопка, вкладка), а `toPoint` связи «за край» — минимум на 4 клетки за полем, иначе обрыв виден.
- `title` — имя области прокрутки для скринридера, `summary` — одна-две фразы о том, что на схеме.
- `defineDiagram()` на сборке падает, если связь ссылается на несуществующий узел.

## Графы: `map`, `flow`, `prototype`

### Узел

| Поле | Что |
|---|---|
| `id` | уникален в диаграмме |
| `type` | `screen` · `entry` · `decision` · `input` · `flowLink` · `start` · `group` · `frame` |
| `at` | `[x, y]`, клетки |
| `w`, `h` | необязательны. Умолчания: высота экрана 5, ромб 16×16, рамка прототипа 24×42 |
| `label` | `{ en, ru }` |
| `num` | номер экрана (карта) |
| `actions` | строки-действия под экраном, узел получает пунктирную рамку. `{ label, external? }` |
| `dim` | бледный общий префикс (флоу) |
| `wire` | вайрфрейм рамки прототипа: `bar` `title` `text` `row` `card` `button` `field` `image` `tabs` `tabbar` `gap`; `'row*3'` — три строки |

`group` — пунктирная рамка с явными `at`, `w`, `h`. Узлы внутри неё — обычные узлы с координатами внутри рамки.

### Связь

| Поле | Что |
|---|---|
| `from`, `to` | id узлов |
| `exit`, `enter` | стороны `l` `r` `t` `b`; без них — из взаимного положения |
| `bend` | координата ствола Z-маршрута: x у горизонтальной связи, y у вертикальной. Одинаковый `bend` у веток одного родителя даёт гребёнку |
| `via` | точки излома в клетках, когда L и Z не хватает |
| `answer` | `'yes'` \| `'no'` — таблетка на линии сразу за ромбом |
| `arrow` | наконечник; по умолчанию есть у флоу и прототипа, у карты нет |
| `dim` | бледная связь префикса |
| `hotspot` | прототип: точка нажатия в клетках от левого верхнего угла рамки-источника |
| `toPoint` | прототип: связь без цели уходит в эту точку поля, можно за край |

### Шапка флоу

`heading: { lead: { en: 'User flow', ru: 'User flow' }, name: { en: 'Top up', ru: 'Пополнение' } }`. Если флоу два и у второго общий префикс, это два файла: у второго префикс помечен `dim`.

## Лист библиотеки: `library`

| Поле | Что |
|---|---|
| `heading` | заголовок листа |
| `fontFamily` | семейство продукта. Шрифт не грузится, без него образец набран Manrope |
| `type[]` | `{ style, usage, size, lineHeight, weight, sample }` — кегль и интерлиньяж в px продукта |
| `colors[]` | `{ name, hex, tints?: [{ name, hex, alpha? }] }`; `alpha` — процент |
| `palette` | `primary`, `primaryPressed`, `primaryLight`, `ink`, `muted`, `line`, `surface`, `error` — ими окрашены наборы |
| `radius` | скругление контролов продукта, px |
| `sets[]` | `{ title, items: [{ block, state?, label, hint? }] }` |

Блоки: `button` `field` `row` `checkbox` `radio` `toggle` `tab` `badge`. Состояния: `default` `pressed` `light` `focus` `filled` `disabled` `error` `on`. У поля `hint` — подпись над значением; у пустого поля (`default`) показывается только она.

Hex и px здесь — данные чужого продукта, и это единственное место, где они допустимы. Цвета нашей ДС в лист не идут.

## Пример

Четыре полных образца — `kit/map.ts`, `kit/flow.ts`, `kit/prototype.ts`, `kit/library.ts`. Отрисованы на `/kit` в светлой (EN) и тёмной (RU) теме.
