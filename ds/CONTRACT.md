# DS Contract — правила работы с дизайн-системой в этом проекте

**Источник ДС:** `ds-baseline`, поставлена с нуля
**Носитель:** код. `ds/tokens.css` — источник правды по токенам, `ds/motion.js` — по движению
**Figma:** не используется. Решение владельца от 2026-08-24; при возврате к Figma она станет **зеркалом** кода, а не источником
**Дата постановки:** 2026-08-24

---

## Главное правило

При любом задании, которое касается интерфейса — новый экран, новая секция, новая карточка, доработка существующего — работаем строго через эту ДС. Новый экран = композиция из существующих компонентов и существующих токенов. Прибитые цвета, размеры, радиусы, шрифты и длительности в обход токенов запрещены.

## Что значит «через ДС»

1. **Компоненты — только из каталога.** Список в `ds/components.md`: `Navbar`, `TextLink`, `CopyEmail`, `MediaFrame`, `MediaZoom`, `ProjectDialog`, `WorkRow`, `MetaList`, `SectionHead`, `ProseBlock`, `NoteBlock`, `DecisionBlock`, `Footer`. Новые под конкретный экран с нуля не рисуются. Композиции, не ставшие компонентами, — в `ds/patterns.md`: обложка `FeaturedCase`, карточка Webflow-сборки, `CaseHeader`, сетка `CaseSystem`, оболочка страницы.
2. **Цвет — только смысловым токеном.** `var(--text-default)`, не `#1B1B18`. Обращаться к примитиву (`var(--gray-900)`) прямо из компонента тоже нельзя: примитивы существуют только для того, чтобы на них ссылался смысловой слой.
3. **Типографика — ролью, не числами.** Классы `ds-display-*`, `ds-heading-*`, `ds-body-*`, `ds-meta-*`. Прибитый `font-size` в компоненте — баг.
4. **Отступы и радиусы — токеном.** `var(--space-12)`, не `48px`. **Вертикаль — шкалой ритма, а не примитивом `space-*`:** `var(--flow-node)`, `var(--section-gap)`. Шкала и её механика — `ds/foundation.md` §«Вертикальный ритм». Компонент собственной внешней вертикали не несёт вовсе: отступ принадлежит промежутку, а не узлу, и пишется одним направлением — `margin-block-start` на нижнем.
5. **Движение — только через `ds/motion.js`.** Компонент берёт `motion.hover`, `motion.revealText` и так далее, не `duration: 0.24` россыпью. Каждая анимация регистрируется внутри `withMotionPreference()` — это единственная точка отключения по `prefers-reduced-motion` (`MOT-01`), включая переходы между страницами.
6. **Мобильный — самостоятельная раскладка, не сжатие.** 360 px расчётный, не крайний случай (`SCR-09`, `TECH-08`).

## Что делать, если нужного нет

**Нет компонента под задачу.**
1. Проверить, не собирается ли он композицией существующих. Плитка Webflow-сборки — это `MediaFrame` + `MetaList`, а не новый `Card`.
2. Если действительно нужен — добавить в `ds/components.md`: имя, назначение одной строкой, варианты, используемые токены, требования доступности.
3. Только после этого реализовывать и ставить на экран.

**Нет смыслового токена.**
1. Добавить в слой 2 `ds/tokens.css` со ссылкой на существующий примитив.
2. Если подходящего примитива нет — добавить и его в слой 1.
3. Записать в `ds/foundation.md`.
4. Только после этого использовать.

**Нужен новый цвет.** Проверить контраст до внесения, не после. Текст — 4.5:1, крупный текст — 3:1, граница, несущая смысл, — 3:1 по WCAG 1.4.11. В проекте уже был случай, когда нейтрал пришлось перекрасить из-за 3.62:1 на 12 px.

**Нет паттерна композиции.** Дописать в `ds/patterns.md`: имя, из каких компонентов и токенов собирается, что в нём нельзя переставлять. Файл заведён 2026-08-24 и держит пять паттернов; при сборке экранов он референс, а не пожелание.

## Синхронизация файлов ДС

Шесть файлов обязаны сходиться. Расхождение ломает следующие сборки.

| Файл | Что держит |
|---|---|
| `ds/foundation.md` | человекочитаемая спека токенов, обоснования решений |
| `ds/tokens.css` | те же токены исполняемо — **источник правды** |
| `ds/motion.js` | motion-слой для GSAP: секунды и имена кривых |
| `ds/components.md` | каталог компонентов |
| `ds/patterns.md` | композиции из компонентов: что собирается без новой сущности |
| `ds/motion-concept.md` | словарь движений: какое движение, где применяется, что делает в `reduce` |

С 2026-08-24 у двух из них есть исполняемые зеркала в коде — они обязаны совпадать побайтово:

| Источник | Зеркало |
|---|---|
| `ds/tokens.css` | `src/styles/tokens.css` |
| `ds/motion.js` | `src/scripts/motion.js` |

Правка идёт в `ds/`, копия обновляется тем же коммитом. Проверяется `diff`; расхождение ломает следующие сборки так же, как расхождение внутри `ds/`.

- Правишь `tokens.css` → сразу правишь `foundation.md`. Motion-токен → правишь ещё и `motion.js`.
- Добавляешь компонент → сразу строка в `components.md`. Если у компонента есть движение → строка в §3 или §7 `motion-concept.md`.
- Собрал узел экрана из существующих компонентов → строка в `patterns.md`, чтобы следующая сборка не изобретала его заново.
- Меняешь motion-токен → проверяешь, какие из пяти движений на нём стоят, и правишь их описание.
- Не заводишь параллельный набор токенов в конфиге фреймворка. Тема Tailwind, если появится, **выводится** из `tokens.css`, а не дублирует его.
- Брейкпоинт правится в `ds/tokens.css` в двух строках сразу: примитив `--bp-*` и условие `@custom-media --bp-*`. Одна без другой — расхождение CSS и JS.

## Что запрещено

- Прибитые цвета, кегли, межстрочные, радиусы, отступы, длительности в компонентах и на экранах.
- Внешний вертикальный отступ в компоненте — `margin-bottom` на корне и любой его вид. Он складывается с шагом контейнера, и одна пара начинает давать разные числа на разных маршрутах. Компонент объявляет роль в цепочке классом-меткой (`ds-flow-heading`, `ds-flow-lead`), расстояние задаёт поток.
- Вертикаль экрана, написанная в две стороны сразу: `margin-bottom` у одного узла и `margin-top` у соседа складываются, а не задают шаг.
- Обращение к примитивному токену напрямую из компонента в обход смыслового слоя.
- Прибитые значения в смысловом слое `tokens.css` — это инвариант, на нём держится ребрендинг.
- Анимация мимо `withMotionPreference()`.
- Создание компонента «на лету» в составе экрана, если его можно вынести в каталог.
- Перезапись существующих токенов новыми значениями без согласования — это ребрендинг, отдельный процесс.

## Когда правила можно нарушить

Только при явной команде «здесь без ДС, ad-hoc» — например, одноразовый рендер под презентацию. Тогда отдельный файл вне `ds/`, явно помеченный как ad-hoc и не часть продукта.

## Motion

Правила движения — в `ds/motion-concept.md`, принята 2026-08-24. Читать вместе с этим контрактом при любой задаче, где что-то двигается.

Словарь закрытый: **пять движений** — Набор, Раскрытие, Строка, Состояние, Переход. Движения, которого нет в §3 концепции, в продукте не существует. Новое движение заводится тем же порядком, что новый компонент: сначала запись в концепцию с указанием, какое содержание оно обслуживает, потом реализация.

Концепция легла на motion-слой без единой правки токенов — `tokens.css`, `motion.js` и `foundation.md` не изменялись.

## Стек

**Astro + GSAP, компоненты `.astro`, деплой Vercel.** Решение владельца от 2026-08-24, обоснование — `ds/motion-concept.md` §2.

Следствия для контракта:

- Тема Tailwind не заводится; `ds/tokens.css` подключается напрямую и остаётся единственным источником правды по токенам.
- `react-base`, `screens`, `storybook`, `wire` в этом проекте не применяются: одиннадцать статичных компонентов каталог не окупают, витрина `src/pages/index.astro` закрывает визуальный QA. Обратный путь при необходимости — `.tsx` внутри Astro без client-директив; токены и motion-слой при этом не трогаются.
- GSAP подключается одним общим скриптом базового layout. Это единственная JS-зависимость **продукта**: в браузер не уходит больше ничего.
- **Сборочная зависимость одна — `postcss-custom-media`, заведена 2026-08-24 аудитом экранов.** Решение владельца: медиазапросы обязаны брать брейкпоинт из ДС, а `@media` не читает `var()`. Плагин разворачивает `@media (--bp-md)` в число на сборке; объявления живут в `ds/tokens.css` и в выходной CSS не попадают. Раздаёт их по scoped-блокам локальный `scripts/postcss-breakpoints.mjs` — готовый `@csstools/postcss-global-data` не взят, он прикладывает `tokens.css` целиком и плодит мёртвые скоупленные правила (замерено: 138 против 10, `npm run check:css`). Параллельного набора токенов это не заводит: конфиг читает тот же файл.
- Следствие для `MobileNav`: фокус-ловушка написана руками, Radix Dialog не берётся — он потянул бы React ради одного компонента. Это отменяет пункт 2 §«Что заимствуется» в `ds-strategy.md`.
- Компонент не пишет анимаций. Он объявляет движение атрибутом `data-motion`, хореографию ведёт `src/scripts/animations.js`. Словарь атрибутов — в шапке этого файла и в `ds/components.md` §Реализация.
