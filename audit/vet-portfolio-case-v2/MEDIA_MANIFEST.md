## Complete-screen inspection

The hero, calculation, invoice, discharge and state details resolve to full desktop/mobile sources through the shared MediaZoom. Owner comparison uses a complete desktop article and a genuine native mobile context/plan/prescription crop, with full views linked independently. Mobile does not display a squeezed desktop screen. No product Before/After claim is made; historical portfolio/reference images are research evidence only.

## Reproduce

Run the clean current product on port 5370, then `node audit/vet-portfolio-case-v2/capture-product.mjs` and `node audit/vet-portfolio-case-v2/build-media-manifest.mjs`. Capture uses existing external Playwright tooling, not a new site dependency. `PRODUCT_REPO`, `PRODUCT_URL` and `PLAYWRIGHT_PACKAGE_JSON` can override local defaults.
