# Motion implementation and evidence

Existing GSAP/ScrollTrigger/SplitText and motion tokens are retained. No Lenis, alternate framework, scroll controller, counters or timers were added. Hero typography uses existing lines/fade and one coordinated fade-image. Large editorial headings and investigation evidence reveal once. Body paragraphs stay static.

The only shared edit is an import and lifecycle-owned call in `src/scripts/animations.js`. Necessity: creating an independent Astro component initializer would duplicate media-preference and page teardown ownership; the current buildCaseScenes already owns structural case motion, restored reading and cleanup. `src/scripts/agent-reading.js` returns immediately on every page without the Agent-only selector. It registers through the existing withMotionPreference branch and returns a responsive cleanup.

At the existing lg breakpoint and at least the existing measure-lead (800px) viewport height, one native sticky approval stays beside three editorial explanations. Native scroll updates only the outside-UI current-stage color/border. The financial interface remains whole and unchanged throughout; it never implies execution. There is no hidden text, pin, spacer, timed swap or additional scroll distance. Proof width is bounded by viewport height through semantic spacing, preserving complete controls and caption. On narrow/short, reduce and no-JS, all explanations and the complete approval form a static composition.

Reduced-motion preference destroys the responsive scene and removes current-state attributes. Astro before-swap disposes it through the existing lifecycle; history traversal creates structural reading state without replaying intro. Reversing scroll restores the matching stage. Native anchor links and zoom remain active. Final frames, transition positions, lifecycle and keyboard checks are recorded by `scripts/agent-premium-v3/functional.mjs` under `after/` and `functional.json`.

This is a restrained reading guide, not an animation of product execution. Current markers change discretely at the reader’s stage; no claim of reproducing Garri’s live animation.
