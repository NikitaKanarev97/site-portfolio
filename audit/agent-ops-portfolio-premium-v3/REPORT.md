## Reproduction and limits

Scripts are in `scripts/agent-premium-v3/`: capture, references, specimens, boards, protected, functional and performance. They use the already installed product Playwright package and Chromium executable, with no added dependency. Build must finish before preview/captures start. Preview port 4406 serves the final production build; temporary dev QA config/port 4405 supplies existing diagnostics and is not committed.

Browser verification is Chromium on this Windows environment. Safari/Firefox, actual touch hardware, constrained networks and a human recruiting read test were not run. Existing capture-only RU string completion remains disclosed in V2 provenance. The three-state specimen does not establish a newly audited complete design-system catalog. Current external reference sites were not recaptured. Independent reviewer still determines **ACCEPTED**, **ACCEPTED WITH BACKLOG** or **REVISION REQUIRED**.
