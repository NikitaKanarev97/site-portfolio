Camera connection · 7 MIN READ

Camera not found via ONVIF

Start with the connection settings. Automatic discovery is only one way to add a device: a camera reachable over the network can also be connected manually.

Learning sample · TRASSIRReviewed 7 September 2026
01

Check camera connectivity

From the video surveillance server, check the camera address and whether its web interface is accessible. If the device is unreachable, check power, the switch connection and routing between networks. A ping response alone does not confirm that ONVIF is working.

02

Check ONVIF settings

In the camera settings, check that ONVIF is enabled, which port it uses and which account has the required permissions. These settings depend on the model and firmware. The ONVIF port may differ from the web interface port.

03

Add the device manually

In TRASSIR settings, open IP devices and select ONVIF. Enter the model, address, port and the camera account credentials. If the model is unknown, use model detection. Once detection succeeds, create the device.

04

Check the result

Make sure video is visible, the correct stream is selected and recording works. If the connection fails, save the exact error message, camera model, TRASSIR version and firmware version. These details will help support identify the problem.

EXPECTED OUTCOME

The camera is added and video is available. If the issue persists, you have the connection settings and exact error ready for diagnosis.
