# Приоритизация по MoSCoW

**Дата:** 24 августа 2026 · **Проект:** Site-portfolio · **Вход:** `outputs/features_list.md` (89 позиций)

> **Критерий Must, применённый буквально.** Фича попадает в Must, если выполняется хотя бы одно: (1) она напрямую обслуживает JTBD одной из двух primary-персон — П1 «за минуту решить, стоит ли отклик времени лида» и П2 «понять, как человек думает в ограничениях»; (2) без неё основной сценарий физически невозможен; (3) это table stakes — рыночный стандарт жанра, отклонение от которого платное.
>
> **Почему Must такой большой.** 69 из 76 фич — это не 69 модулей. Больше половины Must стоят одну строку текста, один атрибут или одно архитектурное решение, принятое до первой строки кода: подпись роли, строка NDA, `canonical`, `matchMedia`. Дорогих позиций внутри Must ровно девять, и они отмечены отдельно — именно они, а не длина списка, определяют срок. MoSCoW здесь работает не как способ урезать объём (дедлайна нет, бриф §1), а как **порядок**: что не имеет права отсутствовать в момент, когда первая ссылка уйдёт в отклик.

Без них запуск бессмыслен: сайт либо не проходит машинный и рекрутерский фильтр, либо проходит его и не выдерживает второго читателя.

### Техника и определение готовности (15)

| ID | Фича | Почему Must |
|---|---|---|
| TECH-01 | SSG или SSR, не CSR | 78–82% первичного отсева машинные. Задним числом не чинится — CSR-сайт не превращается в статический правкой |
| TECH-02 | ≥1500 символов текста в DOM без JS на каждой странице | Условие прохождения первого фильтра, поднято из motion-ограничений в технические |

| TECH-04 | Пер-страничные мета и `canonical` | У конкурента ссылка на кейс превьюится как главная. Входит в критерии готовности наравне с motion |
| TECH-05 ✱ | OG-картинка с названием кейса | Пересылка в Slack — часть воронки; превью формирует мнение второго читателя до открытия |
| TECH-06 | Настоящий HTTP 404 | Конвенция платформы; у конкурента 200 на несуществующем URL |
| TECH-07 | `sitemap.xml` с кейсами и `robots.txt` | Table stakes индексации |
| TECH-08 | Адаптив desktop / tablet / mobile | Планка «не хуже шаблона за $79»: очков не даёт, провал опускает ниже медианы |
| TECH-09 | LCP < 2.5 s, зелёные CWV на мобильном | Иначе сайт противоречит собственному обещанию. Метрика успеха №6 |
| TECH-10 | woff2, оптимизация изображений, ленивое видео | П3 откроет DevTools. 373 КБ блокирующих TTF у конкурента — готовый пример цены |
| TECH-11 | Контент в файлах, добавление кейса = добавление файла | Портфолио проектируется как растущее; версия 1 — первая из пяти волн |

| TECH-15 | Ни одного рантайм-механизма, способного заблокировать читателя | Самая дорогая ошибка конкурента (severity 4). Отказ, реализуемый как запрет |
| TECH-16 | Индикаторы измеряют реальное состояние или отсутствуют | Выдуманный процент — прямое свидетельство против сайта, продающего внимание к деталям |

## Won't have (now) — 6 позиций

Осознанно откладываем. Не в этой версии.

| ID | Фича | Почему не сейчас |
|---|---|---|
