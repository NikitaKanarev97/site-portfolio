# Agent Ops — предыдущая художественная версия, 03.10.2026

Исторический отчёт. Эта версия не прошла художественную приёмку: вход стал выразительнее, середина осталась презентацией интерфейса. Продолжение — `agent-ops-checkpoint-review.md`. Технические проверки ниже не доказывают сильного вау-эффекта.

Локальный результат: http://127.0.0.1:4330/preview/agent-ops-pilot/. Прежний checkout, без коммита и публикации. Art direction заменяет художественную композицию S3, а не запускает новый обязательный чат. Опубликованные EN/RU и главная не переносились.

## Что изменилось

Обложка выражает «между обещанием и выплатой появляется человек»: точное сообщение слева, сумма справа, Human review между ними. Реальные панели сходятся с двух сторон и останавливаются; конечная композиция сохраняется без движения. Небольшой поворот и разная высота создают образ, при этом целые панели остаются читаемыми. На mobile собственная вертикальная композиция и горизонтальный шлюз.

Середина — один устойчивый центр, а не pin предыдущего пункта под следующим. Кластеры → весь workspace → целая переписка → карточка approval. Пропорции материалов меняются, верх текста и визуальный центр сохраняются. Заголовки и UI меняются при полном контрасте, без смешанных полупрозрачных кадров; только входящий материал смещается на 24 px. Это конечная последовательность по нативному scroll, без wheel interception или постоянного RAF.

На ширине от 1024 и высоте от 820 — одна закреплённая сцена. На mobile, коротком окне, reduce и no-JS — полный естественный список. Дополнительная desktop-переписка скрыта на mobile, где она уже является narrow-материалом workspace. Нумерация остаётся 01/02/03.

## Исправление полей по обратной связи

Кластеры и transcript раньше были сняты по границе прозрачного внутреннего блока: заголовок и левый акцент касались новой тёмной рамки. Внешнее серое поле не устраняло проблему. Пересняты целые реальные DOM-блоки с полем исходного surface-page: 32 px на desktop, 24 px на mobile, из токенов прототипа. Текст и ширина содержимого до/после обрамления совпадают. Отступ одинаков с четырёх сторон; изображение сохраняет новую естественную пропорцию. Файлы продукта не менялись.

Подтверждение: `scripts/shoot-pilot-panel-insets.mjs`, `research/portfolio-benchmark/shots/pilot-art-direction/panel-insets/measurements.json`. Используются новые `clusters-framed-*` и `transcript-framed-*`; исходные слишком тесные кадры сохранены для сравнения. Evidence и approval проверены: собственные внутренние поля уже есть. Внешняя CasePlate остаётся отдельным уровнем подачи.

## Проверка композиции

Сохранены и просмотрены 1440×900, 1024×900, 390×844, короткий 1440×600, live resize до 360×780. Запись `verification.json` содержит 11 комбинаций/режимов, остановки перед/после всех обменов, обратный и быстрый scroll, обычный клик на Partner Portal и Back, reduce/nojs, три live reduce/full цикла и пять resize.

В закреплённом режиме во всех остановках виден ровно один непрозрачный материал; полный кадр помещается в окне. Нет горизонтального overflow, битых изображений и JS-ошибок. Back восстанавливает scrollY с допуском 2 px; допустимое изменение позиции ссылки из-за восстановления SplitText <32 px. Live reduce/full сохраняет верх текущего довода с допуском 3 px. На resize снимается исходный transform изображения, чтобы mobile не наследовал горизонтальное смещение. Смена предпочтения возле Next case сохраняет этот блок. Эти проверки не являются оценкой вкуса владельца.

Переносимые opt-in варианты: `CaseCover proof layout=interlock`, `CaseSteps variant=focus`, `desktopOnly`. Код движения — `src/scripts/animations.js`; параметры — `ds/motion.js` и побайтовое зеркало. Обновлены карта, компоненты, foundation и motion-concept.

`npm run check`: 0 errors, 0 warnings, 101 прежний hint. Build успешен. Check CSS: 0 dead rules. Harmony: 0 нарушений на двух preview и /kit при 1440/1024/390. Noindex сохраняется; опубликованные маршруты не менялись. Для resize/reduce выполняется конечный пересчёт положения в .18 s, отменяемый жестом чтения. В Back структурная сцена восстанавливается без нового вступления.

После окончательной сборки проверены `/`, `/about/`, оба опубликованных `/work/` кейса и `/ru/` на 1440/390: ошибок, overflow и новой focus-сцены нет. Данные — `shots/pilot-art-direction/published-regressions.json`. Единственный dev на 4321 перезапущен после сборки: зависимости загружаются, ошибок и дублей сцен нет. Production preview остаётся на 4330.

## Финальный production-замер

После новой съёмки повторён тот же `measure-pilot-production.mjs`: 3 последовательных прогона каждого профиля, Chromium, 200 rAF с scrollBy 48 px, локальная сеть без ограничения. Другие браузерные проверки и кодирование видео в этот момент не выполнялись. Исходный S3 baseline сохранён.

| Профиль | P95 S3 / Art, ms (медиана 3) | Кадров >34 ms, Art (каждый из 200) |
|---|---|---|
| 1440, CPU ×1 | 17.0 / 17.7 | 1 / 0 / 0 |
| 390, CPU ×1 | 16.9 / 17.0 | 0 / 0 / 0 |
| 1440, CPU ×6 | 26.4 / 33.8 | 5 / 9 / 15 |
| 390, CPU ×6 | 24.6 / 33.8 | 7 / 10 / 9 |

В этом финальном прогоне CPU ×6 хуже S3. TaskDuration медиана выросла .287 → .346 s desktop ×1 и .239 → .259 s mobile ×1; ×6 — 2.761 → 3.316 s и 2.277 → 3.032 s. Гарантии плавности на слабом устройстве нет. Это CDP-эмуляция на текущей машине, не физический телефон, Lighthouse или полевые CWV; разницу нельзя выдавать за доказанный эффект одного CSS/asset изменения. Итоговые данные: `outputs/agent-ops-art-production.json`, компактная таблица — `agent-ops-art-performance-summary.json`. Ошибок JS в 12 пробах нет.

3D-пререндер не нужен для работающего результата. Если позже появится отдельный фильм, UI берётся реальными текстурами; это не условие завершения текущего пилота. Художественная приёмка принадлежит владельцу. Переносы EN/RU, главной и публикация требуют отдельного задания.
