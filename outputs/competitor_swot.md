# SWOT по конкурентам — в контексте нашего проекта

> Шаг 1 из 4 по навыку `competitive-analysis`. Собран 24 августа 2026 на основе `brief.md`, `competitive_analysis.md`, `deep_research_results.md`. Сверен с источниками при полном прогоне 24.08.2026 — расхождений не найдено, содержание оставлено без изменений.
>
> **Как читать.** S и W — про сам конкурент. O и T — что это значит для нас: O = чем мы можем воспользоваться, T = чем он нам опасен. Это не оценка людей и не рейтинг, а разбор стратегий.

## 1. Simon Pan — simonpan.com

*Product Designer, ex-Uber / Google / Amazon / Medium. Эталон нарративного кейса под найм.*

| | |
|---|---|
| **S** | Девятиблочная структура кейса, до сих пор лучшая из существующих; блок **Reframing the Problem** — сильнейший приём жанра. Результаты в бизнес-рамке с цифрами (−20% ожидания, −34% ошибки точки подачи). Имя и бэкграунд FAANG работают сами по себе. | **W** | **Сайт целиком под паролем** — 401 на всех страницах, проверено 24.08.2026. Motion отсутствует: сайт доказывает мышление и ничего не доказывает об исполнении. Вся сила упирается в цифры, то есть в разрешение публиковать метрики. Три кейса, обновлений не видно. |
| **O** | Ниша «глубокий кейс, открытый без пароля» сейчас **буквально пуста** — эталон, на который ссылаются все разборы, недоступен по ссылке из отклика. Его структуру можно взять целиком: она общедоступна через десятки разборов и не является чьей-то собственностью. Мы добавляем к ней то, чего у него нет — исполнение. |
| **T** | Его структура — это тот шаблон, с которым hiring manager подсознательно сравнивает наш DSSL. Кейс без цифр рядом с этим эталоном читается как более слабый, если мы не подставим на место метрики что-то равносильное. Угроза реальная и адресуется правкой №1 из `deep_research_results.md`: место цифры занимает **названный компромисс**. |

## 2. Andy Reff — andrewreff.com

*Product Designer, 20+ лет. React + GSAP + Vercel + Sanity. Awwwards Honorable Mention 21.03.2026, 7,6/10.*

| | |
|---|---|
| **S** | Единственный, кто собрал ровно нашу связку и получил за неё награду: product-first позиционирование + тяжёлый GSAP + code-first. Selection Expand Transition — тот самый переход «карточка растёт в hero» из нашего motion-раздела. `prefers-reduced-motion` реально поддержан. Собственная UX-аналитика: rage-клики, dead-клики, глубина скролла. Ответ на NDA через `noindex/nofollow` вместо пароля. |
| **W** | **28 символов текста без JS** — пустой DOM, чистый CSR. Главная тоже: без JS нет даже имени и роли. AI-командная палитра с голосом впечатляет дизайнера и не даёт рекрутеру ничего за 30 секунд. Проектные страницы исключены из sitemap целиком, то есть невидимы и там, где скрывать нечего. |
| **O** | Наше преимущество здесь **конкретное и измеримое**, а не вкусовое: тот же класс движения при 1500+ символах в DOM. С учётом того, что 78–82% первичного отсева в 2026 машинные (`deep_research_results.md`, раздел 2), его сайт для первого фильтра выглядит пустым — а наш не будет. Приём `noindex` берём в резерв для NDA-чувствительных материалов. |
| **T** | Самый опасный конкурент из пятерых: он уже занимает позиционирование, к которому мы идём, и уже подтверждён наградой. Если наш сайт выйдет позже и будет читаться как «то же самое, но аккуратнее», выигрыш будет незаметен снаружи. Отстройка обязана быть **содержательной** — глубина кейса, — а не только технической. |

## Сводка: три вывода из SWOT

**Единственная общая слабость всех пятерых — никто не совмещает глубину и исполнение.** Simon Pan и Emil Kowalski сильны содержанием при нулевом движении, Dennis Snellenberg и Andy Reff — наоборот, Rauno вне этой оси. Пересечение S одних с W других и есть наша позиция.

**Главная угроза — Andy Reff, и она содержательная, а не техническая.** Он занимает то же позиционирование, уже награждён и вышел раньше. Победить его аккуратностью вёрстки нельзя — можно только глубиной кейса, которой у него не видно.

**Самая недооценённая возможность — craft-лента Rauno.** Она дешёвая, она усиливает формулу «сайт сам себе доказательство», и она частично закрывает единственный по-настоящему серьёзный риск проекта — один раскрытый кейс в версии 1.
