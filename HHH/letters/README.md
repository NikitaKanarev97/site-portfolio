# Архив отправленных писем — русский рынок

Заведён 2026-09-02. Ведётся скиллом `ru-cover-letter` (`.claude/skills/ru-cover-letter/`).

Один файл — один отправленный отклик: `ГГГГ-ММ-ДД-<компания>.md`. Файл создаётся, **когда отклик отправлен**, а не когда письмо написано. Счёт ведёт `HHH/pipeline.md` — здесь только тексты.

Зачем: гейт требует сорока откликов, и на сороковом вопрос будет не «сколько отправлено», а «чем письма приглашённых отличались от писем молчавших». Без архива на него нечем ответить. Второе назначение — не повторить один зацеп дважды за неделю: перед сборкой письма смотрятся последние 3–5 файлов (пункт 11 гейта).

## Шапка файла

```
# <Должность> — <Компания>

Ссылка: <URL вакансии>
Площадка: <hh / Хабр Карьера / getmatch / Telegram / почта>
Полоса: <A/B/C/D> · Итог: <X.X> · Читатель: <рекрутер / лид / фаундер> · Отправлено: <дата>
Ответ: <нет / дата и что ответили>

## Письмо
...

## Ответы на встроенные вопросы вакансии
...
```

Строка `Ответ` дописывается задним числом. Она и есть материал недельного разбора.
