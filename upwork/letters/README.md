# Архив отправленных писем

Заведён 2026-09-01. Ведётся скиллом `upwork-proposal` (`.claude/skills/upwork-proposal/`).

Один файл — один отправленный отклик: `YYYY-MM-DD-<slug>.md`. Файл создаётся, **когда отклик отправлен**, а не когда письмо написано. Счёт откликов при этом ведёт `upwork/pipeline.md` — здесь только тексты.

Зачем: гейт G4 требует шестидесяти откликов, и на шестидесятом вопрос будет не «сколько отправлено», а «чем письма ответивших отличались от писем молчавших». Без архива на него нечем ответить. Второе назначение — не повторить один зачин дважды за неделю: перед сборкой письма смотрятся последние 3–5 файлов.

## Шапка файла

```
# <Заголовок вакансии>

Ссылка: <URL вакансии>
Полоса: <A/B/C/D> · Итог триажа: <X.X> · Connects: <N> · Отправлено: <дата>
Ответ: <нет / дата и что ответили>

## Cover letter
...

## Ответы на вопросы
...
```

Строка `Ответ` дописывается задним числом. Она и есть материал недельного разбора.
