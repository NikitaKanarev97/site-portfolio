# Исследование обложек Upwork и применённая система

Дата: 4 сентября 2026

## Итог в одном абзаце

Для портфолио на Upwork сильнее всего работает не рекламный постер, а крупный, настоящий интерфейс: в присланной выборке 20 из 24 уникальных обложек (83%) построены вокруг продукта, а красные рукописные пометки не встречаются ни разу. Красные стрелки и before/after заметнее в Project Catalog, где картинка продаёт услугу «UX audit». Поэтому из новых обложек убраны и одинаковые красные подвалы, и декоративные рукописные элементы: остались только интерфейс, фон из палитры проекта и аккуратная продуктовая подача.

## Что повторяется у сильных кейсов

| Приём | Наблюдение | Решение для наших обложек |
|---|---|---|
| Один крупный интерфейс | Самый частый и самый читаемый паттерн | Главный экран занимает большую часть карточки |
| Своя палитра кейса | Карточки связаны уровнем подачи, но не одним цветом | Фон взят из палитры каждого продукта |
| Минимум текста поверх | Название Upwork уже показывает под карточкой | Убраны универсальные подписи и рекламные обещания |
| Плоский скрин вместо устройства | Интерфейс остаётся видимым на маленьком превью | Нет ноутбуков, телефонов и перспективных мокапов |
| Несколько экранов только по смыслу | Before/after, responsive и mobile flow — оправданные исключения | Vet показывает responsive + клиническую деталь; Pawly — один мобильный journey |
| Красная разметка — не система портфолио | Сильнее связана с audit-услугами Project Catalog | Не используется без содержательной функции |

## Почему сохранён размер 2000×1600

Upwork рекомендует загружать портфолио-изображения размером 1000×750; допустимый диапазон — от 400×300 до 4000×4000. Для Project Catalog отдельно указан формат 4:3 и проверка на читаемость при 1000×750. В репозитории уже используется 2000×1600, поэтому этот размер сохранён, а весь важный контент помещён в центральную безопасную область 2000×1500: при автоматическом 4:3-кропе ничего важного не пропадает. [Требования портфолио](https://support.upwork.com/hc/en-us/articles/39295662788115-Why-won-t-my-portfolio-item-publish), [правила Project Catalog](https://support.upwork.com/hc/en-us/articles/1500011309082-How-to-add-images-and-video-to-your-Project-Catalog-project).

## Официальные ограничения, учтённые в дизайне

Upwork рекомендует выбирать только лучшие работы, не перегружать изображения, не добавлять контактные данные и проверять превью перед публикацией. Для Project Catalog отдельно запрещены text-heavy, плохо обрезанные, размытые, clickbait-изображения и водяные знаки. [Рекомендации для портфолио](https://support.upwork.com/hc/en-us/articles/360016144974-How-to-enhance-your-freelancer-profile), [правила изображений](https://support.upwork.com/hc/en-us/articles/1500011309082-How-to-add-images-and-video-to-your-Project-Catalog-project).
