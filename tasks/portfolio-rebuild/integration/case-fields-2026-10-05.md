## Повторение

```text
node scripts/shoot-learn-frame-fields.mjs http://127.0.0.1:4475
npm run build
node scripts/verify-case-fields.mjs http://127.0.0.1:4475
FIELDS_BROWSER=webkit node scripts/verify-case-fields.mjs http://127.0.0.1:4475
node scripts/verify-site-rhythm.mjs http://127.0.0.1:4475 390,820,1440
```

Для PowerShell WebKit выбирается через `$env:FIELDS_BROWSER='webkit'`. Capture использует текущий локальный экспорт Learn и fixture `state-marina-ready` из исходного проекта. Браузерные проверки — на адаптивных viewport в Chrome/WebKit, без утверждения о проверке на физическом устройстве.
