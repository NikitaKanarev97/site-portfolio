# Скругления, поля и исправления сетки

Обе локали используют общие компоненты. Внешние медиаконтейнеры — 16 px, внутренние кадры — 8 px. ScreenSurface добавляет 16 px в цвете исходной поверхности; цвет читается на сборке отдельно для широкого и узкого источника. Native образцы компонентов сохраняют собственный alpha-контур. Дополнительные поля включены в расчёт закреплённых сцен и увеличения кадров.

CaseCallout получил отдельное внутреннее поле для номеров от 768 px. Номера и линии находятся внутри белой рамки; на телефоне остаётся легенда под кадром. Результат Agent Ops выровнен по основной колонке страницы. От 1024 px заголовок и цифры идут по левой оси, пояснения — по правой; ниже идут последовательно.

В bundled Learn исправлена общая ширина блока следующего действия и кнопки завершения. Полная навигация переснята из настоящего прототипа: EN/RU × desktop/mobile. Общий stylesheet включён во все 128 entry points, чтобы прямые ссылки и переходы внутри приложения давали одинаковый результат; sync:learn сохраняет его подключение при последующем экспорте.
