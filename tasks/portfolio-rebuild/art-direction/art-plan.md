# H · направление реализации

Авторская подача реальных решений: крупный вход → тёмный рубеж человека → синяя исходная строка → редакционная модель материала → клиническая передача → фотографическое подтверждение.

1. Home: роль крупнее, краткий двухколоночный пакет и видимый индекс пяти работ. Первая сцена Agent Ops следует без прежнего большого зазора. Вместо пяти одинаковых 16:9 подиумов — собственная геометрия и смысловой материал каждого проекта.
2. Agent Ops остаётся флагманом: оплаченный и принятый прототип, сильная сцена checkpoint. Сохраняем interlock и факты; усиливаем главную и финальную развязку. Не меняем fixture $420/$340 и оценочный статус 71/2.4h.
3. Portal: row 38 как крупный редакционный ориентир рядом с целой native панелью, затем прежние конкретные map/flow/DS. Источник прослеживается до корзины; post-order snapshot отсутствует.
4. Learn: два входа вокруг одного материала; доступное сопоставление настоящих кадров вместо повторения общей pin-сцены. Прочитано/завершено/попытка различаются.
5. Vet: вход от ограничения 30 секунд, настоящий QuickTrace и самостоятельная передача между ролями. Не выдаём demo за клиническое внедрение.
6. Pawly: существующая demo-фотография крупно, настоящие mobile UI и явный переход selected → confirmed. Native manual film и три матрицы остаются.

Статика сначала. Смысловые entrances и короткий отклик после неё; no-JS/reduce сохраняют весь материал. Никаких дополнительных forced pin-полей. Новые варианты сначала зарегистрированы в DS. После реализации — визуальное сравнение, EN/RU desktop/mobile, walkthrough всех шести маршрутов и необходимые lifecycle/resize проверки.

# H4 · продолжающаяся художественная доводка

Ответ исполнителя на обязательный вопрос после H3: **пока нет, скорее аккуратно, чем мощно**. Технически завершённая правка рамок не завершает художественное поручение. Независимый контроллер проверяет frozen H3 (7e2ae63); H4 производится последовательно в том же checkout, с отдельным preview 4395, без подмены его проверяемой версии 4394.

Наблюдаемые слабости: generic роль в небольшом масштабе не задаёт авторскую идею; все пять работ имеют одну цветную оболочку и одинаковый заголовок/материал/нижнюю строку. Разница фото, интерфейса, нескольких ролей и системного материала сглаживается.

Изменения H4: крупный двухстрочный вход о сложных системах и ясных решениях с явно названной ролью, настоящим approval UI и пятью быстрыми входами; тёмный Agent как флагман; Portal как широкая предметная плоскость с 38; Learn как документ и его программный контекст; Vet как связанный след одного визита; Pawly как фотография рядом с подтверждённым отчётом. Цвет принадлежит материалу, а не всем одинаковым карточкам. Native изображения показываются целиком внутри белых полей; внешние медиапанели radius16; общий лайтбокс и отдельный текст остаются.
