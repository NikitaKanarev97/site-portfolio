## 2. По каким осям направления расходятся

Чтобы варианты нельзя было перепутать, каждое направление занимает свою позицию по всем осям из PLAN-CHATS, 2.3. Цвет — последняя ось, а не первая.

| Ось | A. Ведомость | B. Справочник | C. Пульт заказа |
|---|---|---|---|
| Что ведёт в строке | **Код товара**: SKU первым, название вторым | **Название**: читается как статья каталога | **Наличие и цена**: правая часть строки сильнее левой |
| Плотность строки (1440) | **40 px** | **56 px** | **64 px** |
| Типографика | Узкий гротеск + моноширинный только для SKU | Гуманистический гротеск + антиква только в заголовках | Плотный гротеск с крупными табличными цифрами |
| Композиционный ритм | Сплошная разлинованная сетка: шапка, рельс и таблица на общих линейках | Два поля: тонированный рельс-указатель и белый лист | Строка из двух зон: «что» слева, тонированная полоса заказа справа на всю высоту таблицы |
| Форма элементов | Прямые углы, волосяные линии, без заливок контейнеров | Текст и ссылки вместо контейнеров, малые радиусы | Одна выраженная форма — капсула «количество + действие» |
| Характерный компонент | Строка ведомости: номер позиции, моно-SKU, однострочное название | Рельс со схемами форм-фактора камер | Полоса заказа с капсулой |
| Модель акцента | Цвет только у **состояния** («в корзине»), действия — чернилами | Цвет у **навигации и ссылок** | Цвет **массой на действии** |

## 3. Направление A — «Ведомость»

**Принцип.** Каталог как техническая спецификация, по которой собирают заказ: строки пронумерованы, коды читаются однозначно, всё лежит на одной линейке. Интерфейс не украшает данные, а разлиновывает их.

**Польза для закупщика.** Все 8 позиций и строки «Price not confirmed» видны без прокрутки; сравнение по колонкам — один взгляд по вертикали; SKU, по которому закупщик ищет и сверяет спецификацию (поиск в шапке начинается со SKU), стоит первым и не путается: в `KX-2CB4046F2-I` есть и `I`, и `1`, и `0`.

**Референсы (кадры в приватном пакете).**
- R1 Octopart — строка ≈ 32 px, числа вправо, валюта отдельно от числа.
- R3 Finviz — колонка `No.` у строки, цвет закреплён за немногими смыслами. Тёмная тема **не** берётся.
- R6 Farnell — основание цены в заголовке `Price (ex VAT)`; поле количества и `Add` в одной ячейке.
- Слой 1 DSSL — строка ~43 px: закупщики работали с такой плотностью (только вывод, кадр закрыт).

**Ориентиры.**

| | Значение |
|---|---|
| Шрифты | Fira Sans Condensed 400/500/600 — интерфейс и таблица; Fira Mono 400 — только SKU |
| Таблица | название 13/16, SKU 12/16 моно, характеристики 13/16, заголовки колонок 12/16 500 в обычном регистре; цифры табличные, деньги и количества вправо |
| Заголовок страницы | 20/24 600 в строке с хлебными крошками; отдельного блока H1 нет |
| Строка | 40 px: SKU и название двумя строками по 16 px + 8 px отступ; разделитель 1 px |
| Элементы управления | 28 px по высоте (на desktop больше минимума 24 px по WCAG 2.5.8); на 390 — 44 px |
| Картинка товара | 28×28, обесцвеченная |
| Сетка | шаг 4 px; заголовок таблицы отделён линией 2 px цвета текста, без серой плашки |
| Радиус | 0 у контейнеров, 2 px у полей и кнопок |
| Поверхность | бумага: тёплый почти белый лист, текст — почти чёрные чернила; без теней |
| Акцент | один «маркер» — только у строки «в корзине» (номер позиции и метка `In cart: 1 · Undo`). `Add to cart` — кнопка чернилами |

    │ │ 4 MP object-detect bullet…  │      │              │      │           │                        │

**Вторичное состояние «Price not confirmed».** Строка остаётся на линейке; в цене — прочерк, в наличии — `Price not confirmed` и `Stock not confirmed` приглушённым цветом, степпер и кнопка заблокированы, `Ask your manager for a quote` — в ячейке действия. Тексты — нынешние. Без красного (REFERENCE-MAP, секция 10).

**390 (открытая гипотеза).** Строка без контейнера, ~112 px: SKU и название; характеристики одной строкой через точки; цена и наличие справа; степпер и действие строкой ниже. На экране — 5 позиций.

**Правила и запреты.** Моно — только SKU, не подписи и не числа. Никаких серых плашек, карточек и теней. Подписи колонок в обычном регистре. Цвет не появляется ни на чём, кроме состояния «в корзине» и фокуса.

**Что выигрываем.** Максимальная плотность без потери подписей — прямой ответ на U1 аудита (43 → 66 → 81 px) и на тезис кейса «вернуть плотность без хаоса». Самый «инженерный» характер из трёх.

**Чем рискуем.** Может читаться как Excel или как незаконченный интерфейс. Мелкие зоны нажатия на desktop. Плотная техническая таблица — ближайшая к Agent Ops по плотности: светлая бумажная поверхность и узкий гротеск обязательны, тёмная тема и моно в теле таблицы запрещены, иначе сольётся на тесте подмены. Fira Mono для SKU нарушает п. 1 стоп-листа, если не будет записан в системе продукта с причиной (различимость `I/1/0/O`).

## 4. Направление B — «Справочник»

**Принцип.** Каталог как отраслевой справочник: иерархию держит текст — заголовок, ссылка, описание, — а не контейнеры. Слева тонированный указатель со схемами, справа белый лист со списком.

**Польза для закупщика.** Подбор по форм-фактору и характеристикам читается, а не расшифровывается: подкатегории и фильтры объяснены схемами, у чисел — тихие единицы. Хорошо для инженера по подбору и для закупщика, который ещё не знает точный SKU.

**Референсы.**
- R2 McMaster-Carr — сдержанные поверхности, текстовая иерархия, серая подложка рельса, схематичные пиктограммы вместо фото в фильтрах, счётчик над списком.
- R4 TradingView — единица мелким тихим суффиксом (`2.8 mm`, где `mm` тише числа).
- M1 Лемана ПРО — нулевое и неподтверждённое — словами, без плашки.

**Ориентиры.**

| | Значение |
|---|---|
| Шрифты | Source Sans 3 400/600 — интерфейс и таблица; Source Serif 4 600 — только заголовок категории и заголовки групп рельса |
| Таблица | название 14/20 600 цветом ссылки, SKU 12/16 приглушённо, характеристики 14/20, единицы — тише числа; табличные цифры |
| Заголовок страницы | антиква 28/32; под ним служебная строка `8 products · All models: PoE · Your price · ERP · today 11:42` 13/20 |
| Строка | 56 px: название и SKU + 2 × 10 px |
| Элементы управления | 32 px; на 390 — 44 px |
| Картинка товара | 40×40, рендер без обработки |
| Рельс | тонированная полоса во всю высоту страницы; группы фильтров — заголовок антиквой, значения ссылками со счётчиками; подкатегории Bullet / Dome — линейные схемы форм-фактора (рисуются в SVG, новых данных нет) |
| Радиус | 3 px у полей и кнопок; контейнеров нет |
| Поверхность | белый лист и тонированный рельс — две поверхности, третьей нет |
| Акцент | один «каталожный» цвет: навигация, хлебные крошки, названия товаров, значения фильтров и заливка `Add to cart`. Не синий по умолчанию (#2563EB нынешней ДС — тот самый дефолт, U9) |

**Анатомия строки, 1440.**
```
┃ RESOLUTION          ┃  ▭  4 MP object-detect bullet camera    4 MP   Fixed 2.8 mm   IP67     $149.00    24 Moscow DC   [− 1 +]  In cart: 1 · Undo
┃ ☐ 2 MP          1   ┃     KX-2CB4046F2-I                                                     excl. tax  ships 1–2 days
┃ ☐ 4 MP          5   ┃ ─────────────────────────────────────────────────────────────────────────────────────────────────────
```

**Вторичное состояние.** Название остаётся ссылкой; в ячейке цены и наличия — нынешние `Price not confirmed`, `Stock not confirmed` и `Ask your manager for a quote` приглушённым цветом, одной колонкой; степпер и кнопка заблокированы.

**390 (открытая гипотеза).** Компактная статья без рамки, ~150 px: название-ссылка, SKU, характеристики строкой; цена и наличие; степпер и действие. Рельс — в нижний лист «Filters» (как сейчас).

**Правила и запреты.** Антиква — только в заголовках, никогда в данных. Цвет — у навигации, ссылок и одной кнопки действия; статусы цветом не кодируются. Не добавлять карточки, «воздух» вокруг строк и пояснительные абзацы — справочник держится на плотном тексте, а не на пустоте.

**Что выигрываем.** Самый читаемый вариант; рельс со схемами — фирменный приём, которого нет у конкурентов из пакета, кроме McMaster.

**Чем рискуем.** Ближе всех к «обычному приятному сайту»: может не пройти тест подмены, если схемы и антиква окажутся единственными отличиями. **Пересечение с TRASSIR Learn:** у Learn задача — длительное чтение и путь к ответу, и антиква с текстовой иерархией могут оказаться естественным языком именно Learn. Если владелец выберет B, на 2.7 Learn придётся уводить от этого языка — это ограничение, которое лучше знать сейчас. Строка 56 px плотнее прода (66), но реже направления A.

## 5. Направление C — «Пульт заказа»

**Принцип.** Каталог как рабочее место оформления: справа на всю высоту таблицы идёт тонированная полоса заказа — цена, наличие, количество, действие. Левая часть отвечает на вопрос «что это», правая — «беру ли и сколько». Цвет сосредоточен там, где принимается решение.

**Польза для закупщика.** Решение «брать или нет и сколько» принимается по цене, остатку и сроку (01-AUDIT, раздел 8) — эти числа самые крупные на экране и стоят на одной вертикали. Действие и его результат («в корзине») не теряются в строке.

**Референсы.**
- R5 ЧИП и ДИП — количество и срок одной ячейкой со знаком доставки; компактный степпер рядом с одной главной кнопкой; фирменный цвет на действии.
- R7 Промэлектроника — подписанные количества наличия как главные числа строки.
- R6 Farnell — количество и `Add` одним блоком.
- M2 METRO — единица рядом с ценой.

**Ориентиры.**

| | Значение |
|---|---|
| Шрифты | Golos Text 400/500/600 — весь интерфейс |
| Таблица | название 14/20 500, SKU 12/16, характеристики 13/16 приглушённо; цена 17/24 600 и остаток 17/24 600 табличными цифрами; склад и срок 12/16 под остатком |
| Заголовок страницы | 24/32 600 |
| Строка | 64 px — в пределах ориентира 66 px (прод слоя 2) |
| Элементы управления | капсула 36 px; на 390 — 44 px |
| Картинка товара | 44×44 |
| Полоса заказа | тонированная колонка от заголовка таблицы до последней строки, отделена от левой зоны вертикальной линией; в заголовке полосы — `Your price · excl. tax`, `Available`, `Quantity` |
| Капсула | степпер и `Add to cart` — один элемент с полным скруглением; после добавления капсула заливается и показывает `In cart: 1 · Undo`. Полное скругление — только у капсулы, остальное 2 px |
| Акцент | один тёплый сигнальный цвет массой — на капсуле действия и состоянии «в корзине»; полоса — тёплый нейтральный тон. Остаток и цена — чернилами, без цвета |

**Анатомия строки, 1440.**
```

    KX-2CB4046F2-I                                               ║  excl. tax   ⛟ 1–2 days
 ────────────────────────────────────────────────────────────────╫────────────────────────────────────────────────────────
 ▭  8 MP dome camera                   8 MP  Fixed 2.8 mm  IK10 ║  Price not confirmed · Ask your manager for a quote   ( ─ ─ ─ ─ )
```

**Вторичное состояние.** В полосе заказа строка без цены и остатка: нынешние тексты `Price not confirmed`, `Stock not confirmed`, `Ask your manager for a quote` на месте двух чисел, капсула пустая и заблокированная, без цвета.

**390 (открытая гипотеза).** Строка из двух ярусов, ~140 px: сверху картинка, название, SKU, характеристики; снизу на всю ширину — тонированная полоса заказа: цена, остаток, капсула. На экране — 4–5 позиций.

**Правила и запреты.** Сигнальный цвет — только капсула и «в корзине»; не на ценах, не на статусах наличия, не на ссылках. Полоса заказа — единственная тонированная зона экрана; блоки Workspace и рельс фильтров без заливки. Иконка доставки — единственная пиктограмма в строке.

**Что выигрываем.** Самая ясная иерархия действия из трёх — прямой ответ на замечание ревью «три кнопки без иерархии» (U6). Полоса заказа — сильный и узнаваемый на тесте подмены приём.

**Чем рискуем.** Ближе всех к интернет-магазину — риск, названный в аудите для каталога (01-AUDIT, раздел 4, A). Если капсулу и полосу перекрасить в нейтральный серый, характер может держаться только на цвете — это нужно проверить тестом подмены уже на 2.4. Полоса отнимает ширину у названия: длинные названия (`4 MP full-colour motorised bullet camera`) уйдут в две строки при 64 px.

Ни одно направление не вводит новых данных, функций, фильтров и не меняет сортировку.

## 7. Гипотезы данных — как их принимает каждое направление

Обе гипотезы — Stage 3 по отдельному решению (01-AUDIT, раздел 10, п. 4–5). Здесь только проверка, что ни одно направление их не закрывает.

### 7.1. Остатки по складам колонками (H1) — требует модели остатков по складам

Сейчас у товара один склад; в 2.4 колонки не делаются. Схема на будущее:

```
A:  … │   $149.00 │ MSK  SPB  KZN │ 1–2 d │ [−│ 1│+] Add      — три узкие колонки по 48 px, ноль — «–» приглушённо
B:  … вид списка: [Specs] [Stock by warehouse] — при втором виде колонки характеристик заменяются складами (R1, R3, R4)
C:  … полоса заказа: «24 available ▾» — раскрытие строки со складами внутри полосы (M1, M2)
```

| Задача | A — колонки в строке | B — переключение вида | C — раскрытие в полосе |
|---|---|---|---|
| T1 Хватит ли N штук на нужном складе | сразу, по колонке склада | после переключения вида — сразу | по каждой строке, раскрытием |
| T2 Собрать позицию с одного склада | вертикальный скан колонки — сильнее всех | так же после переключения | слабо: читать каждую строку |
| T3 Сколько всего и когда | нужна сумма или итоговая колонка | в виде Specs — сразу | сразу (сводка в полосе) |
| T4 390 px | колонки не помещаются — сводка с раскрытием | сводка с раскрытием | то же раскрытие, что на desktop |

Проход — экспертный, живых закупщиков нет (01-AUDIT, раздел 7). Нули показываются прочерком или словами, не числом 0 и не скрытием склада (M1 `…0d28`).

### 7.2. РРЦ вторым числом (H2) — поле новое, в 2.4 не добавляется

Иерархия из 01-AUDIT, раздел 8: партнёрская цена главная, РРЦ тише, с подписью `RRP` у числа, маржа не считается, у строки без подтверждённой цены РРЦ не показывается.

| | Где помещается второе число |
|---|---|
| A | вторая строка ячейки цены, 12/16 приглушённо — строка остаётся 40 px |
| B | вторая строка ячейки цены вместо `excl. tax` (подпись уходит в заголовок колонки) |
| C | под ценой в полосе заказа, 12/16; цена остаётся крупной |
