## Мини-задачи

1. Используй ранее проверенную навигацию. Прочитай только код/данные материалов, прогресса, практики, попытки и документа. Для начальных состояний используй существующие демонстрационные fixtures в `audit/product-polish/evidence/07/` и маршрутные подсказки из `07-demo.md` по необходимости.
2. Пройди в EN и RU: материал → программа/плеер → завершение единицы → личное пространство. Подтверди, что чтение и завершение остаются разными показателями.
3. Проверь практику с неверным ответом и объяснением, допуск к зачёту, попытку, результат и восстановление попытки после reload. Перевод не должен менять правильные ответы и расчёт результата.
4. Проверь загрузку ранее сохранённого RU-демосостояния в EN, даты/числа/плюрализацию, сертификат и скачиваемый HTML-документ. Не переводи принудительно произвольные данные пользователя; отделяй их от системного текста.
5. Проверь ключевые учебные экраны EN/RU на 1440 и 375. Устрани только реальные дефекты этой локализации. При изменениях интерфейса соблюдай ДС.
6. После исправлений запусти из Learn `npm run build -- --base=/prototypes/learn/`, `npm run routes`, `npm run test:pilot`. Не запускай аудит всех экранов заново. Сохрани точные результаты и фактическое покрытие.
