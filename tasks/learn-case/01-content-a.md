# 01 — Перевод первой партии

Работай по общим правилам `STATE.md`. Результат: 99 недостающих переводов ID 534–632 в существующем числовом словаре.

## Мини-задачи

1. В `D:/Claude-projects/learn/src/i18n/` прочитай из `content-source.json` только записи этой партии. Проверь отсутствующие ID в `content.en.json`, не перечитывая все 440 готовых переводов. Поле `files` используй для точечного уточнения смысла.
2. Переведи отсутствующие записи на естественный английский. Сохрани технический смысл, числовые условия, правильные ответы, placeholders `{0}`, `{1}`, начальные/конечные пробелы. Не отправляй тексты во внешние сервисы перевода.
3. Добавь переводы в `content.en.json` с числовыми ключами. Существующие переводы не переписывай; преобразование ключей делает этап 03.
4. Программно проверь валидность JSON, покрытие всех фактических ID этой партии, непустые значения и сохранность placeholders/значимых пробелов. Сравни с исходным состоянием, чтобы подтвердить сохранность прежних записей.

Термины: material → resource; программа/траектория → learning path; зачёт → assessment; допуск → eligibility; освоение → resources read; пусконаладка → commissioning; сдача объекта → site handover. Канонические идентификаторы не переводить.

## Приёмка и остановка

Если исходное состояние не менялось: 539 переводов, осталось 73 ID 662–734. Зафиксируй реальные числа в STATE.md. Браузер, сборку приложения, лендинг и портфолио на этом этапе не запускать. Следующий этап — 02.
