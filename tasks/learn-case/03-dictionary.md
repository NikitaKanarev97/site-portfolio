# 03 — Подключение итогового словаря

Зависимость: 02 готов. Работай по `STATE.md`. Результат: учебный контент подключён к существующему runtime-переводу.

## Мини-задачи

1. Прочитай `D:/Claude-projects/learn/src/i18n/index.ts`, структуру `content-source.json`, текущих `content.en.json` и `ui.en.json`. Не выводи целиком словари в чат.
2. Сохрани числовую версию в `content.by-id.en.json`, если её ещё нет. Не перезаписывай существующую резервную версию вслепую. Если итоговый файл уже преобразован, распознай формат и не конвертируй повторно.
3. Проверь каждый фактический source ID и преобразуй итоговый `content.en.json` в `{[entry.ru]: translationById[entry.id]}`. Проверь повторяющиеся русские ключи и расхождения переводов; число строковых ключей может отличаться от числа source entries при дубликатах.
4. Проверь пересечения с `ui.en.json` с учётом `{...content, ...ui}` в runtime. Устрани смысловые конфликты точечно. Проверь непустые значения, placeholders, пробелы и непереведённые видимые строки; бренды и технические обозначения сохраняются.
5. При необходимости сохрани небольшой повторно запускаемый валидатор покрытия в `learn/scripts/`. Он должен проверять контракт данных, а не повторять реализацию приложения.
6. Выполни `npm run typecheck` из Learn. Исправь ошибки, вызванные этой локализацией.
