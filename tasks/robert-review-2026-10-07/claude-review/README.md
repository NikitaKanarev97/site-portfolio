## Что открыть визуально

Старый сайт: кандидат из канонического конфига — https://kanarev.com/ . Локальный: свежий сервер из текущего checkout. Например, из D:/Claude-projects/Site-portfolio выполнить `npm run dev -- --host 127.0.0.1 --port 4410` и открыть http://127.0.0.1:4410/ и http://127.0.0.1:4410/ru/ . **4410 — предложенный порт, а не утверждение, что сервер уже запущен.** При занятости выбрать другой порт. Не использовать устаревший dist как локальный результат. Для production-preview при необходимости сделать одну свежую сборку, сохранив служебные каталоги отдельно от работающих Astro-процессов.

Сначала проверять главную сверху вниз: hero → пять product previews → Selected web builds → How I work → контакты → footer. Точные Home-якоря и маршруты кейсов есть в чеклисте. Для доказательств нужны одинаковые ширины старого и нового сайта: 1440 и 360 px, EN/RU; кадры с исходных пользовательских скриншотов не являются полным baseline-снимком страницы.

## Ограничения передачи

Пакет не содержит копию всего сайта и не подтверждает актуальность deployment. Клоду нужен доступ к репозиторию/локальному серверу и старой версии. Архив claude-review-package.zip рядом с этой папкой удобен для передачи Markdown и картинок; относительные картинки галереи работают после распаковки. Не менять код сайта в ходе проверки, не публиковать результат. Публичные статусы проектов проверять по корневому CONTENT-RULES.md.
