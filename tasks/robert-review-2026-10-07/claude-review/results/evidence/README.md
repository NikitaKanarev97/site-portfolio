# Визуальные доказательства проверки

Эту папку заполняет Клод во время независимого аудита. Сейчас здесь нет кадров, подтверждающих исправление.

Сохранять парные снимки старого и локального состояния: одинаковая локаль, ширина и участок страницы. Например home-en-1440-portal-before.png и home-en-1440-portal-after.png. Один кадр можно использовать для нескольких F-пунктов. В итоговом REVIEW-RESULT.md указывать точный файл, URL, viewport и проверенное состояние.

Исходные пользовательские комментарии находятся в ../../screenshots, а не в этой папке. Они не заменяют новый визуальный прогон сайта.
