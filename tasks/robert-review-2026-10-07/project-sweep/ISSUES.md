## Отклонённые кандидаты

- Mono, CAPS, arrows и Demo route **внутри растрового продукта** — документальный UI. Тексты продукта не перерисовывать. Каталог технических значений шрифтов/цветов сам по себе не T1-нарушение; S016 касается его массы в рассказе.
- Числа71/19/38 — метрики/номер исходной строки по содержанию, а не декоративные номера разделов. Даты документа/события и общий год Footer не равны выдуманным годам.
- Copyright ложноположителен по copy; Press play у Pawly относится к настоящему видео. Настоящие carousel/accordion controls не ложные кнопки.
- Скрытые подписи1px для доступности не являются обрезанными словами. DiagramCanvas содержит скрытый список связей; его стрелки не считать видимой редактурой.
- L1 вертикальных групп CaseSpecimen/CaseRoutes/CaseSteps: sameRow=false. LearnStage имеет два ряда; первые карточки первого ряда выровнены. Поворот Agent намеренно задан rotate±3deg и не вынесен в отдельный дефект.
- L2 отрицательные зазоры сравнивают соседние колонки. Зазоры24–25px у split-heading boxes визуально не тесны: line masks расширяют box. Между cover и первой секцией стоят facts; их нельзя пропускать при сравнении gap.
- Белая область Agent на overview — артефакт представления закреплённой сцены полным кадром при scrollY0. Live3100/4150 показывают workspace/decision; пустой кусок не добавлен как L3/L2.
- C2: ближайший фон равен body, но у ScreenSurface есть собственный контур. На просмотренных кадрах края читаются. Порог только по img пропускал рамку предка.
- C1 Vet: светло-серое поле сцены вокруг собственной карточки UI выполняет отделение от сайта, дополнительной белой рамки сайта не подтверждено. Размеры tablet/phone отвечают разным ролям.
- L5: строки таблицы, borders работающих controls, разделение глав About и Footer группируют реальные разделы. Не признаны бессмысленным декором по одному факту border.
- H1/H2/H3: обычные заголовки CaseThesis последовательны48px; About24px соответствует главам эссе, контакт128px — сильный финал. Cover-variants тематически различаются; повтор логической структуры результата полезен сам по себе.
- X1: русская строка Portal — документальная цитата; Vet Clinic OS и имена компонентов — имена;404 специально двуязычная с lang=ru.
- X2: NDA, синтетические данные, имитация платежей/GPS, demo charge/document, ограничения хранения и необходимости экспертной проверки — фактические раскрытия внутри рассказа. Они не требуют механического удаления.
- X3 budget: после исключения документальных/скрытых данных все кейсы в 250–450 словах; таблица EN/RU и методика в03-copy.md. find-duplicate-phrases проверяет только ключи; 10 запусков без дублей ключей не доказывают уникальность прозы.
- I1: портрет About визуально соответствует эталону; искусственное происхождение не установлено. Мелкие вторичные UI-образцы имеют zoom; их содержимое не объявлено дефектным по уменьшенному overview.
- Focus и reduce: видимый outline на проверенных CTA; конечная обложка Agent содержательно совпадает при reduce. Это ограниченная проверка, не полная приёмка доступности.
