## Дополнительные замеры и ограничения кадра

- C1 Agent: .case-screen--frame, белый фон, padding `24px 24px 24px 56px`, shadow1px, внешний box676.8×839.1. Внутри собственная тёмная карточка UI. Источник: CaseScreen.astro:78; включается аннотациями CaseCallout.astro:41. Машинный порог C1 пропустил объект: нужный предок оказался глубже первых четырёх уровней и большая рамка снижает долю площади.
- Tiny zoom-links: Learn EN/RU32px; Pawly EN32/19px, RU34/21px. Это настоящие ссылки раскрытия изображения, а не текст внутри картинки. Источник CaseScreen.astro:44/84.
- Все mobile body widths360px. Правые карточки внутри overflow-карусели не образуют page overflow. Измеренные clipped sr-only узлы не являются обрезанными заголовками.
- Поворот двух панелей Agent задан явно: CaseCover.astro:340/345. Top отличается50px. Это осознанный приём варианта interlock; отдельную L1-находку не создавать без решения менять художественный приём.
- Заголовки кейсов в proof/editorial/screen variants имеют128/96/64px; заголовки сопоставимых обычных секций CaseThesis48px. Различие cover-variants само по себе не признано H3-дефектом. Контакт128px, акцент сохранён.
- Портрет About совпадает с подачей эталона Home; по доступному кадру нет основания объявлять его искусственным. Источник/подлинность фото не исследовались.
- Документальные UI-glyphs, mono и `Demo route` внутри растров не являются редакционной находкой сайта. Пиксели продукта не предлагалось исправлять.
- C3, H2, I1 оценены глазами на обзорах и выбранных кропах; полный аудит каждого состояния/каждого скриншота не выполнен. Чистый общий фон или повтор логической структуры результата не считать ошибкой без конкретной потери смысла.

Повторная съёмка не делалась для уже корректного кадра. Причины дополнительных контролей явно записаны: pinned-сцена отсутствует в полном кадре scrollY0; первый focus-лист содержал Navbar; первый stop-контроль не активировал decision, другой crop не включал левый маркер. Корректные исходные полные кадры переиспользованы во всех остальных находках.

Итоговые решения и приоритеты — ISSUES.md. Доступность проверена в ограниченном объёме: пять CTA одного кейса, mobile-геометрия всей матрицы, один конечный reduce-кадр.
