## Общие правила

**Экономный процесс по уточнению владельца 07.10.2026:**

- В каждом чате обязательные документы прочитать один раз; далее использовать точечный поиск/изменённые участки. Не перечитывать весь каталог ДС и историю планов без нового вопроса.
- Полные логи сохранять в свои файлы. В контекст возвращать сводку, относящиеся ошибки и минимум строк, достаточный для решения. Нужные screenshots смотреть по своей области; общий пакет не означает повторный просмотр всех 33 каждым чатом.
- Локальный пакет проверяет свои компоненты, маршруты и затронутые состояния. Сборку всего сайта, полный harmony и общую визуальную EN/RU desktop/mobile-матрицу после стабильной передачи выполняет один координатор; пакет 07 отдельно закрывает сквозное правило публичных текстов. Уже достаточные проверки не дублировать без изменений, ошибок или конкретного незакрытого риска.
- У shared Astro cache/build outputs один одновременный писатель. Для независимого прогона изолировать служебные каталоги; не запускать повторные конкурирующие сборки. Рабочие чаты передают конкретный проверенный результат, а не ждут циклически, перепроверяя весь сайт.
- Для следующих волн максимум два одновременно выполняющихся рабочих чата. Созданные пакеты сохранить; не плодить дополнительные чаты по одной мелкой правке. Текущие задачи без прямой команды владельца не останавливать.
- Отчёты короткие: что изменилось, чем проверено, конкретная оставшаяся зависимость. Глубокий разбор нужен для художественного выбора и сложной неисправности; обычные правки выполняются напрямую. Настройки моделей не менять автоматически.

Это уточняет прежнее требование каждому чату повторять общие проверки. Качество принимается по тем же визуальным, функциональным и доступностным критериям.

После прямого разрешения владельца экономный порядок также доставлен сообщением четырём активным чатам 01, 03, 05 и 07 (07.10.2026). Чаты 02, 04 и 06 к этому моменту завершены и повторно не запускались. Настройки моделей не менялись; сообщения относятся к оставшейся работе, а не повторному выполнению пакетов.
