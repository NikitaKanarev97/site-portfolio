# Конкурентный анализ: кейсы и портфолио из выборки ментора

Портфолио конкурирует не с продуктами, а с соседней вкладкой: у нанимающего менеджера десять откликов и вечер после рабочего дня. Поэтому оси сравнения — сколько текста, чем держится внимание, как показан результат.

## 2. Кейсы: студии и продуктовые дизайнеры

### Ilya Dounar — MyTeam, Innova Market Insights
Эталон, который Роберт показал первым. Кейс — один экран прокрутки: название и подзаголовок-итог («Measured engagement growth»), строка фактов (Client, Timeline, Industry, Team, Outcome, Challenge), большой кадр на серой плашке, абзац «Project overview», карусель артефактов, одна строка «Approach», три карточки Impact. Карусель — главное: «Initial UX Diagnosis» с красными пометками проблем на старых экранах, «Structural Shift» таблицей «диагноз → решение». Цитата тимлида-пользователя одной строкой. Сухой B2B не прячется — его разбавляют артефактами анализа, а не текстом.
**Забрать:** строку фактов, карусель «было → диагноз → стало», карточки Impact, цитату.
Кадры: `frames/ilyadounar_com_projects_myteam.frames-1.jpg`, `frames/ilyadounar_com_projects_innova_market_insights.frames-1.jpg`.

### HA Interactive — Atlant Telecom, Zenia, Energy Startup
Студия Дунара. Кейсы идут одной лентой: переход между ними — огромное название бегущей строкой поверх цветного фона и кадра следующего проекта. Внутри кейса текста нет совсем — только подписи. Порядок для продукта: обложка (телефоны + название поверх), карта экранов, user flow с ромбами решений, вайрфреймы со стрелками связей, библиотека компонентов таблицей, финальные экраны на серой подложке. Для бренда — сетка логотипа, логотип на фонах, палитра с состояниями (default / hover / active), скетчи на бумаге, экраны, сайт. Energy Startup — фото человека и иллюстрации поверх карточек интерфейса.
**Забрать:** набор артефактов как «скелет» кейса: IA → flow → вайрфреймы → компоненты → экраны. Это ровно то, что у нас есть в `ia/` и `ds/`, но не показано.
Кадры: `frames/hainteractive_com_cases_atlant_telecom.frames-1…5.jpg`, `frames/hainteractive_com_cases_entice_energy.frames-2…4.jpg`.

### Garri Tonakanyan — Yandex Bank
Единственный длинный кейс выборки, который читается легко. Секрет — структура: слева метка раздела капителью (CHALLENGE, SOLUTION, OPPORTUNITY TO STAND OUT), крупная фраза-тезис в 2–3 строки, под ней 2–4 предложения; справа один экран телефона на серой плашке. Пока читаешь, экран меняется: шаги перевода, клавиатура, ошибка. Между главами — фото команды в офисе и лента экранов конкурентов. Тезисы — утверждения, не заголовки разделов: «A disruptive flow for transfers», «One input has all that you may need».
**Забрать:** механику «текст стоит, экран листается» для Agent Ops; тезисы вместо названий разделов; ленту конкурентов.
Кадры: `frames/garri_design_fintech.frames-1…2.jpg`.

### Yuriy Malugin — Smartcat
AI-платформа перевода — ближайший к Agent Ops по теме. Кейс открывается поверх главной как модальное окно. Шапка: название, год, тип, ссылка; абзац контекста; три жирных блока Objective / Solution / Result списком. Дальше заголовки разделов по центру («Document translation», «Subtitle Editor», «Canvas Editor») и крупные экраны на светло-серых плашках с подписью в одну-две строки.
**Забрать:** формулу Objective / Solution / Result; деление по сценариям, а не по этапам процесса.
Кадры: `frames/malugin_me_smartcat.frames-1…2.jpg`.

### Pavel Abramiankou — NordProtect
Каждый раздел — моноширинная метка («Identity verification», «You have to see some data») и одна строка пояснения, дальше экран. Десктопные экраны чередуются с фото телефона в руке — живое фото разрывает однообразие интерфейса. В конце — мерч бренда. Плавающая навигация-таблетка внизу.
**Забрать:** ритм «экран — фото в руке — экран»; метку-строку вместо абзаца.

### Tubik — Mosby's Files
Кейс студии уровня Awwwards: огромное название, подзаголовок в одну строку, абзац-лид слева, таблица справа (Services, Industries, Challenge, What we did, Recognition). Весь текст кейса — в этой таблице. Дальше только визуал на всю ширину: экраны на фотографиях бетона, триптих телефонов, крупные фрагменты.
**Забрать:** таблицу-шапку как единственное место для текста о задаче.

### Daniil Sergeev — Trove; Ivan Annenkov — Яндекс Лавка
Trove: 72 слова, бенто-сетка из двух колонок — паттерн бренда, логотип, карточка цитаты пользователя с фото, телефоны на мягком градиенте, предметы с паттерном. Лавка: левое меню проектов, крупная антиква, цифры выделены цветом прямо в предложении: «A total of 145 shoots were done, including 15 campaigns and 10 playful videos».
**Забрать:** бенто для Pawly; цифры цветом внутри фразы вместо отдельного блока метрик.

### Victor Vorontsov — Multiply
Короткие главы (Challenge, Branding, Design system, Impact) крупным кеглем в правой колонке, между ними — фото мерча и листы дизайн-системы. Финал — бегущая строка «Let's create together» с плавающей картинкой и кнопка «Book 15-min intro call».
**Забрать:** листы дизайн-системы как самостоятельный визуал; CTA на звонок.

### Margarita Romanova — CRM: Документы (Сбер)
Противоположный пример, близкий к нашему нынешнему: статья на 1 000 слов, оглавление сбоку, разделы Контекст → Исследование → Определение задачи → Поиск решения → Прототипирование → Итоги. Но даже здесь текст разбит: схема экосистемы продукта, схема процесса, фото менеджеров в офисе, чипы «плюс / минус» по итогам теста концептов, итоги списком. Это «честная середина» для подробного B2B — и потолок длины, а не цель.

## 5. Общие выводы

1. **Норма длины — 150–500 слов на кейс.** Медиана ~250. Длинный текст допустим только при механике, где каждый кусок стоит рядом со своим экраном (Garri).
2. **Текст живёт в трёх местах:** шапка-таблица фактов, одна фраза-тезис на раздел, карточки итога. Абзацев-обзоров — один, максимум два.
3. **Визуал разнообразен по типу, а не только по экрану.** У сильных кейсов 4–7 типов изображений: экран, телефон, схема, флоу, вайрфрейм, компоненты, фото, скетч. У нас один.
4. **Процесс показывают артефактами, а не рассказом.** Карта экранов, флоу и библиотека компонентов — доказательство работы, которое сложнее выдумать, чем текст.
5. **Результат — типографикой.** Крупная цифра в карточке (Дунар) или цветом внутри фразы (Лавка), и в первом экране главной (Блинков).
6. **Главная — человек + визуал.** Фото, одна фраза, шоурил или сетка обложек, логотипы или отзывы.
