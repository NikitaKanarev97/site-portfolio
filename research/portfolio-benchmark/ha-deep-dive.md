# HA Interactive — детальный разбор, главный донор

**Дата:** 3 октября 2026. Источники: HTML и `main.js`/`main.css` сайта (лежат в `ha-src/`), исходные картинки артефактов в полном размере (`ha-src/*.png`), видео обложки `ha-src/AT_app.mp4`, записи прокрутки `ha-src/rec-case/`, `ha-src/rec2/next/`, `ha-src/rec2/home/`.

## 1. Как устроен сайт

**Стек:** WordPress, jQuery, GSAP 2 (TweenMax, TimelineMax), ScrollMagic, Swiper, свой плавный скролл. Кейсы подгружаются AJAX-ом в контейнер `.case__wrapper` без перезагрузки, адрес меняется через `history.pushState`.

**Главная — лента кейсов.** Весь экран залит цветом текущего кейса (приглушённый фирменный: кирпичный у Zenia, жёлтый у Energy, синий у Telecom). В центре окно с видео размером 50vw × 26vw. Поверх — огромные белые названия на горизонтальной ленте: текущее по центру, соседние торчат по краям. Колесо или свайп сдвигают ленту, фон и видео плавно сменяются (Swiper, `slideSpeed: 1600`). Кнопка «смотреть» плавно следует за курсором (`followMouse`, сглаживание 1/5 по X, 1/2 по Y).

**Вход в кейс** (`zoomInSlider`). Окно с видео растягивается на весь экран (`.promo-video` анимирует width/height/opacity 750 мс, `cubic-bezier(.455,.03,.515,.955)`), название остаётся поверх полупрозрачным. Затем снизу въезжает белый лист кейса (`.-show-case .case__wrapper { transform: translateY(0) }`). При прокрутке белый лист наезжает на закреплённое видео. Шапка переключается в белый цвет, пока под ней видео (`-is-white`).

**Выход в следующий кейс** (`scrollNextCase`). В конце кейса — блок «Название следующего / Next project» и вертикальная линия. Если продолжать крутить колесо на самом дне, линия заполняется (`.case-next-fill`, нужно накопить 500 единиц прокрутки; при паузе больше 250 мс шкала сбрасывается). Когда шкала заполнилась — кейс сворачивается обратно в ленту, лента едет к следующему названию, и он раскрывается тем же увеличением. На телефоне — свайп вверх больше 100 px.

## 2. Обложка кейса — «3D-телефоны»

Это **не WebGL и не код**, а пререндер: `AT_app.mp4`, 1920×1080, 25 к/с, **3,1 секунды в цикле**, 1,4 МБ. Два белых iPhone в 3D на сером фоне `#C9CDD2`→`#E6E7E9`, медленно покачиваются и чуть смещаются друг относительно друга, мягкая тень снизу. Экраны — настоящие макеты продукта. Тег: `<video muted playsinline loop preload="auto">`.

**Что делаем мы:** у HA ролик открывает только стартовый кейс (Telecom Tools). Следующий кейс подан без 3D и по-другому, а сила сайта в смене кейсов. Поэтому ролик у нас один, у стартового Agent Ops: цикл 3–5 с, 1920×1080, H.264 + WebM до 2 МБ, постер. Остальные четыре кейса получают обложку «экран на цвете кейса» со своей подачей. Резерв без видеопроизводства — CSS 3D: скриншот в рамке, `perspective` и медленный `rotateY` ±6°. План — `PLAN-CHATS.md`, этап 4.

## 3. Порядок кейса Atlant Telecom

1. Видео обложки + огромное название поверх (`Telecom Tools`).
2. Белый лист наезжает. Сверху справа строка фактов мелким кеглем в 6 колонок: Year, Location, Industry, Category, Services, ссылка на сайт.
3. **«Aims»** — огромный жирный заголовок слева (5em, отступ 12% слева) и 2–3 строки цели светлым кеглем.
4. Карта экранов (Information Architecture).
5. **«Solution»** — заголовок и 2 строки.
6. Два user flow на одном листе.
7. Карта прототипа — вайрфреймы со связями.
8. Библиотека компонентов.
9. Финальные экраны: три телефона на светло-серой плашке с подписями экранов сверху, затем ещё два ряда.
10. «Next project» + шкала перехода.

Весь текст кейса — около 150 слов. Каждый артефакт — одна картинка шириной во весь контент, плашка `#F0F0F0`, внутренний отступ картинки 4rem (на телефоне 1rem).

## 4. Нотация артефактов — спецификация для перерисовки наших

### 4.1 Карта сайта (`AT_Dashboard_Architecture`, 5022×2835)
| Элемент | Как нарисован |
|---|---|
| Поле | `#F3F3F3`, без сетки |
| Экран | белый прямоугольник `#FFFFFF`, скругление ~6 px, без обводки и тени, текст `#242424` ~18 px, внутренний отступ ~16×38 px |
| Точка входа | тот же блок с тёмной обводкой 1,5 px (`Login`) |
| Номер экрана | синий квадратик `#0989F7` со скруглением 3 px и белой цифрой, **внутри правого верхнего угла блока** с небольшим отступом — связывает карту с прототипом и экранами. Уточнено по оригиналу 04.10: прежнее «наполовину вылезает» было неверной трактовкой |
| Связи | тонкие серые линии 1 px `#CBCBCB`, только горизонтали и вертикали, «гребёнка» со скруглёнными углами; без стрелок |
| Функции внутри экрана | пунктирная скруглённая рамка вокруг блока; под блоком — строки-действия обычным текстом с подчёркиванием во всю ширину (`feedback form`, `book a call`) |
| Внешние ссылки | подчёркнутая строка «to go page on telecom.by» |
| Глобальные экраны | вне дерева, столбиком слева (`Profile`, `Survey`, `Feedback`) или группой в углу (`FAQ`, `Contacts`) |

### 4.2 User flow (`AT-User-Flow`, 2528×1896)
| Элемент | Как нарисован |
|---|---|
| Заголовок | «User flow» чёрным + название сценария серым тем же кеглем, под ним линия 1 px `#787878` во всю ширину |
| Старт | текст «Launch the App» + вертикальная черта-ограничитель |
| Экран / шаг | белый блок без обводки (как в карте) |
| Решение | ромб с обводкой 1 px `#131313`, текст вопроса внутри мелким кеглем |
| Ответы | плашки-таблетки: `yes` — фон `#E5FEDA`, зелёный текст; `no` — фон `#FEDADA`, красный текст; стоят прямо на линии |
| Ввод данных | параллелограмм с тёмной обводкой (`Fill Info`, `Add funds`) |
| Переход в другой флоу | блок с тёмной обводкой (`Top Up Balance flow`) — ссылка, а не шаг |
| Финал | белый блок `Done` |
| Стрелки | 1 px `#8A8A8A`, маленький открытый наконечник, ортогональные, углы скруглены |
| Общий префикс | во втором флоу повторённое начало (запуск → логин) показано бледным (~40% непрозрачности), новая часть — в полную силу |

### 4.3 Карта прототипа (`AT-Prototype`)
Серые вайрфреймы (`#A3A3A3` по белому) в рамке экрана, название экрана над рамкой серым. Связи — голубые кривые `#9BD9FE` 2 px с кружками-хотспотами на месте нажатия. Связи уходят за край — ощущение большого живого прототипа.

### 4.4 Библиотека компонентов (`AT-Library`, 3035×2276)
- Заголовок «Components library» крупно.
- **Типографика** таблицей в 4 колонки: стиль (H1…Auxiliary) · где используется · `size/line-height`, `weight` · живой образец. Строки разделены тонкими линиями.
- **Цвета** карточками: hex мелко сверху слева, имя снизу слева; под основным — оттенки (Primary 700, 300), у полупрозрачных — процент (`15%`, `5%`). Группы: Primary, Neutral 900→200, Errors, Loyalty/Payments, Promo 1–7.
- **Компоненты** — каждый набор обведён **фиолетовым пунктиром** (рамка набора вариантов Figma; цвет на глаз — фиолетовый, как стандартный `#9747FF` Figma, не замерен). Внутри состояния столбиком: кнопки (filled, pressed, light, light-pressed, disabled), поля (filled, empty, focus, disabled, error с helper text и счётчиком 1/16), строки-ссылки (8 вариантов, включая цветные), радио, чекбоксы, иконки сеткой, таб-бар с парами активная/неактивная, промо-карточка, алерт, строки списков.
- Фон `#F0F0F0`, компоненты на нём как есть, без лишних подложек.

## 5. Движение — точные параметры из CSS/JS

| Что | Параметры |
|---|---|
| Появление строк текста | абзац режется на строки (`splitLines`), каждая строка в маске `overflow:hidden`; строка из `translateY(100%)`, `opacity:0` → 0, 1 за **640 мс**, `cubic-bezier(.645,.05,.355,1)`, задержка **+40 мс на строку** |
| Заголовки h2 | так же, целиком, 640 мс; размер 5em, на телефоне 2.6em |
| Картинки | обёртка `opacity 0→1` за 1 с `ease`, внутренний отступ 4rem; срабатывает ScrollMagic-сценой при входе в экран |
| Окно видео | 750 мс `cubic-bezier(.455,.03,.515,.955)` для размера и прозрачности |
| Переключение слайдов главной | 1600 мс |
| Наезд листа кейса | `translateY` → 0, лист белый, видео под ним закреплено |
| Переход к следующему | накопительная шкала 500 единиц колеса, сброс после 250 мс паузы |

## 6. Что берём и как сделать у нас

| Берём | Как у нас (Astro + GSAP ScrollTrigger, `data-motion`) |
|---|---|
| Видео-обложка в цикле с названием поверх | компонент обложки кейса: `<video>` + постер, название поверх — только у стартового кейса; у остальных экран на цвете кейса |
| Белый лист наезжает на обложку | обложка `position: sticky`, контент кейса — белый лист с `z-index` выше; без перехвата скролла |
| Построчное появление | `data-motion="lines"`: SplitText или ручная разбивка, 640 мс, тот же bezier, шаг 40 мс |
| Заголовки-слова «Aims / Solution» | наш модуль «метка + тезис»: тезис выезжает из маски |
| Нотация карты, флоу, прототипа, библиотеки | перерисовать все наши `ia/` в этой нотации — отдельный этап, правила в ДС (`ds/patterns.md` → раздел «Диаграммы») |
| Лента кейсов с цветом и огромными названиями | секция «Selected work» на главной; переход между кейсами — Astro View Transitions + общий элемент обложки |
| Переход к следующему кейсу | в конце кейса — огромное название следующего на его цвете; клик или дальнейшая прокрутка открывают его. **Без** перехвата колеса: шкала только как подсказка, переход по клику и по обычной ссылке |

**Не берём:** собственный скролл вместо нативного (ломает доступность и поиск по странице), обязательное «докручивание» для перехода, jQuery и ScrollMagic. При `prefers-reduced-motion` — всё статично, видео на постере.
