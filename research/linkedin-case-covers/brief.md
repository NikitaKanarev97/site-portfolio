# Brief — LinkedIn Featured case covers

## Goal

Create a coherent cover system for four product-design cases that helps a recruiter or design lead understand the project in a two-second scan and still rewards closer inspection.

## Context

- Placement: LinkedIn Featured links and reusable portfolio/social previews.
- Audience: recruiters, product-design leads, founders hiring for B2B SaaS work.
- Cases: Agent Ops Console, B2B Partner Portal, Vet Clinic OS, Pawly.
- Brand: restrained, precise, observant, confident, human; warm paper, graphite, oxidized orange.
- Non-negotiable: real UI geometry stays exact. Generated media may be used only behind or around the UI.

## Evaluation criteria

1. Project type and domain read at thumbnail size.
2. One real interface remains the visual proof.
3. Title, role/scope and one evidence line are legible.
4. All covers clearly belong to one designer.
5. No generic neon SaaS, fake UI, stretched screens, or decorative device mockups.
