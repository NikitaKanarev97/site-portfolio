# Пакеты для следующих чатов

03.10.2026. Сейчас чаты не запускаются: сначала зафиксирован анализ. После решения начать реализацию использовать задания ниже. Все чаты относятся к одному проекту; создание отдельного чата — явное действие владельца или координатора по его поручению.

04.10.2026: подготовлены [самостоятельные первые сообщения A–G](prompts/README.md). Каждый файл содержит общее начало, точные области EN/RU, условия запуска и передачу результата; его можно копировать целиком. Пакеты ниже остаются исходной спецификацией заданий. Подготовка сообщений не меняет статус реализации.

## В каком порядке использовать пакеты

A → приёмка и общая база → B+C → интеграция первой пары → D+E → интеграция второй пары → F в свободном слоте → G → финальная проверка. F может идти параллельно с B/C или D/E после заморозки общих файлов, если у него свой checkout. Для полного запуска четырёх кейсов одновременно нужны отдельные ветки/checkout и один интегратор общих запросов.
